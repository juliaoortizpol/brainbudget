2. Install Node 24 + npm, Python 3.12+, Git, Codex with the existing authorized ChatGPT login, and an isolated MongoDB. No mongod or Docker executable was found on this machine's PATH. Do not substitute a production MONGODB_URI.
3. Implement/validate a seed/reset against a dedicated disposable database. Use two synthetic users (own/other-user authorization), institutions, accounts, active/closed/deleted budgets/items, manual/ambiguous/rule matches and duplicate synthetic mail fixtures. Guard reset by loopback/dedicated database allowlist and a synthetic ownership marker; abort on unexpected collections/data. No general drop-database command is supplied.
4. Install locked dependencies in isolated checkouts. Backend requires MONGODB_URI even in test/development and instantiates Google strategies: use explicitly synthetic local values for startup; real OAuth/Gmail flows need separate authorized test credentials. Never copy a user's .env. Seeded passwords are test-only and must not be captured in screenshots/logs. Static fixtures/unit mocks do not establish API integration.
5. Start exact pinned builds with a supervisor that refuses occupied ports and records process id, source commit, environment, readiness and cleanup. Existing frontend proxy expects /api → localhost:3000; Vite is normally 5173. Backend /health reports service liveness, not database readiness or commit identity. Test a real database-dependent synthetic request and served-build provenance before recording readiness. Backend currently listens without a loopback host restriction: provide host/container isolation rather than silently changing application behavior during setup.
6. Provision browser automation/screenshot storage in the separate QA session. Desktop chat browser availability does not prove the isolated CLI has a browser tool. Verify actual UI/API requests, normal/empty/loading/validation/error/responsive states; store captioned evidence under the run scratch root. Do not expose JWTs, real mail or financial data.
7. Record an operator-owned environment manifest (fields in orchestration/README.md), including exact frontend/backend commits and seed/reset evidence. Register it with the controller's environment command. A changed commit invalidates it. A missing prerequisite produces BLOCKED with owner/next action.
